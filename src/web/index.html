距离度量 f

预设
f(t) 表达式（t ≥ 0，严格单增，f(0)=0）

距离 d = F(f(|Δx|)+f(|Δy|)+f(|Δz|))，F = f⁻¹，力幅取 F(d)。f = t² 即欧氏距离（各向同性，能量严格守恒）；其余度量各向异性，力幅随方向变化（角动量仍严格守恒，能量近似），预设会自动调小 dt。

力律 F

预设
F(r) 表达式（r 为度量距离；正 = 吸引指向对方，负 = 排斥）
耦合常数 G = 1.00（自动标定）

两体加速度 a = G·mⱼ·F(d)·(xⱼ−xᵢ)/|xⱼ−xᵢ|：力恒沿连线指向施力对象，总角动量对任意度量严格守恒。势能 V = G·∫F dr 由内核导出（幂和项解析积分，其余数值积分）。f = t²（欧氏）时能量也严格守恒；各向异性度量下力幅随方向变化、力场非保守，报告的能量会漂移——这是「中心力 × 度量距离」模型的内在特性。

G 自动标定：保持 G·F(R/2) = 0.04（R 为随机云半径），即任何盘半径 / 力律下「半半径处的力」都与默认配置（R=10、F=1/r²、G=1）相同——换设置时演化时标保持一致。改盘半径或力律后重新「应用」即可更新。

3D 模式在球体内均匀生成。初速度取「包围质量圆速度 × 旋转系数」（纯切向、±8% 弥散），近平衡初始化；旋转系数偏离 1 或自行调小 dt 前的近距交会都会让盘弛豫加热、轨道变扁——那是真实引力物理，能量与角动量仍守恒。

暗物质晕：固定于原点、永不移动、不参与并合（紫色），但对所有质点施加全部引力；反弹模式下表现为不可推动的弹性壁。
