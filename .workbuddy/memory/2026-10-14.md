## 同日追加：Barnes-Hut 树 + 速度倍率（用户第 6 轮需求）—— 实测记录

**树实现（core/sim.cpp ~400 行）**：懒子节点四叉/八叉树，θ 判据 mrad<θ·d（度量距离表述），
碰撞检测用 minMetricDistToBox 精确下界剪枝，PE 估计器 θ_PE=min(θ,0.25)。

**修掉三个连环 bug（全部实测定位）**：
1. `step()` 里 `cachedEnergy_ = energy()` 死缓存：每步白跑一次建树+PE 遍历（树模式 0.6s/步 → 删除后仍慢）。
2. **反扫 com 双重加权**（核心 bug）：子节点向父节点推 com·m，而 com 已是加权和 →
   com 沿树炸到 1e8 → 单元永不开启 → 每体 1285-1934 交互（比直接求和还慢）。
   修复：统一「原始加权和」不变量，父子直接相加，最后统一除 m。
   修后 2D 满盘 θ=0.6 每体 ~67 交互。此前「树力正确」的结论不受影响
   （不开启就下钻到叶，结果对但慢）——误差 θ² 收敛曲线本身就是迷惑性证据。
3. **T11 能量爆炸不是树 bug**：测试用密度 1e9 → 半径 5.6e-5 → 核内简谐 ω·dt≈37 ≫ 2 →
   Verlet 指数发散。密度改 1e4 后 200 步 dE/E=4.6e-4。

**实测基准（gs_bench.exe，2D 满盘，单线程）**：N=2000 直接 247ms vs 树 21.6ms（11×）；
N=4000 988 vs 47ms（21×）；32k 树 499ms/步近线性。3D 常数大 4×。
力误差（环形域 3000 体）：θ=0.4 max 2.1e-2/mean 3.4e-3；θ=0.3 max 8.4e-3。
gs_test 31 项全过（含 T11：力/PE/冷盘积分）。

**速度倍率 + 服务器架构修复**：
- setup/control 新增 speed(0.25..64)/tree/theta；每 tick 步数=substeps×speed(≤512)。
- **锁饥饿三连环**：① tick 循环持锁整个批量（2500 体×64 步=1.4s）→ 每 tick 墙钟预算 70% + 自适应 chunk；
  ② SSE 每帧 energy() 树 PE 遍历 30ms → 降频缓存（n≥1000 每 15 帧）；
  ③ 大 N JSON 载荷 → SSE 帧率分级 30/12/8Hz。
- **前端拖尾自适应**（2500 体×240 拖尾让 headless 渲染 97fps 吃光 CPU 拖垮服务器）。
- E2E 验证（server/verify_speed_tree.py）：控件齐全、×16 生效（小系统真加速）、
  2501 体 3D 树运行 ΔE/E₀=-6.5e-6、无 console 错误。headless 软渲染是最坏场景，
  大 N 速率受整机 CPU 竞争限制属预期。

**3e8 可行性（答复用户的要点）**：3e8 粒子×64B≈19GB 内存（单机吃紧）；
BH 每步 ~8.4e9 交互，本机单线程 ~4000s/步。博主必然用了 GPU 和/或 PM/FFT 方法。
本机 CPU 现实目标：交互式 1-2 万体（2D）/ 4-8 千（3D）；升级路径：多线程（×核数）
→ CUDA（×50-100）→ TreePM/多重极（FMM）。

## 「轨道越来越扁」排查（结论：真实物理，非积分器 bug）

写 `server/eccentricity_test.py` 跟踪 E/L/偏心率（可复跑）。实测：
- f=t² 时总角动量被 Verlet 守恒到舍入（1e-12~1e-15）——哪怕 E 因近距交会爆炸（A 组
  dE/E=+66）L 也纹丝不动。理论依据：速度 Verlet 的 ΔL = dt/2·(τ_n+τ_{n+1})，
  中心力对（成对反向+沿连线）瞬时总扭矩恒 0 → L 精确守恒。
- UI 默认（ρ=100 核正则化）：E 漂移 ~1e-6，L ~1e-15，但 ⟨e⟩ 从 0.27 涨到 0.63（t=24，
  ~28 个动力时标）——自引力盘的二体弛豫（Poisson 团块散射加热），真实物理。
- f≠t²（如 t^1.5）：欧氏角动量模型本身不守恒（无旋转对称），L 漂移 ~0.1，内在特性。
- 修法（初始化侧）：makeCloud 改近平衡——圆速度计入包围质量（中央体+均匀盘/球内含量）、
  纯切向、±8% 弥散、默认旋转系数 1.0（原 0.8 亚圆速度 + ±25% + 随机径向分量，初始 e≈0.3）。
  实测初始 ⟨e⟩ 0.34→0.13，t=24 时 0.88→0.63。剩余弛豫需更大 N / Plummer 软化
  （V=-1/sqrt(r^2+ε²) 用户可自写）才能进一步抑制。

## 第 9 轮：模型语义改为「力律 F + 中心力」（角动量严格守恒）

用户要求：力恒指向施力对象（沿连线）、角动量守恒；UI 从 V 改为 F
（预设 r / 1/r / 1/r² / 1/r⁶−1/r¹²）；内核由 F 推出 V 保持势能架构。

### 约定（改动前必读！）
- **F > 0 = 吸引**（指向对方），F < 0 = 排斥；力 a_i = m_j·F(d)·Δ/|Δ|（Δ=x_j−x_i）。
- **V = ∫F dr**（F = V′，注意不是 −V′）：F=1/r²→V=−1/r；F=1/r→V=ln r；
  F=r→V=r²/2；F=1/r⁶−1/r¹²→V=−r⁻⁵/5+r⁻¹¹/11；常数 F=c 合法（V=cr）。
- V 两条路：**asPowerSum 幂和解析反积分**（新增 Expr::asPowerSum，RPN 符号机，
  覆盖全部预设/测试）+ 数值表兜底（[1e-6,1e6] 4096 点 GL4 对数积分 + Hermite 插值）。
- **中心力 → 角动量对任意度量守恒到舍入**（T12 实测 1.7e-15/2.9e-15 @ t^1.5/t^3）。
- 能量仅在 f=t² 严格守恒；各向异性度量下力场非保守（curl≠0），E 漂移是本征物理。
- 核内正则：力幅 s(d)=F(R)·d/R（不再用 V′(R)）；反弹法向改 Δ̂（f=t² 时与旧一致）。
- 力循环去掉度量梯度（每对省 3 次 pow）→ 大幅加速：N=2000 直接 22ms/步（旧 247）、
  树 1.8ms/步（旧 21.6）；N=4000 直接 134ms、树 4.3ms；32k 树 57ms。
- F 构造校验：r=0.5/1/2 三探测点必须有限（挡掉 1/(r-1) 极点）。
- gs_create 第三参数字符串语义从 V 变 F（签名不变）；server /api/setup 用 "F" 键
  （兼容旧 "V" 键名但语义即力律）。前端 #vPreset/#vExpr id 未改（内容改力律）。

### 验证
- gs_test 47 项断言全过（新增 T2/T3 中心方向/幅值、T2b 一般 F 的 −∇∫F 一致性、
  T5 解析+ln+LJ+数值表反积分、T8 极点拒绝/常数接受、T12 角动量）。
- eccentricity_test 复跑：f=t^1.5 组 dL/L 从旧模型 −5%~−9% 变 1e-14（本征特性确认）。
- 排坑：测试期望公式曾错写 |a|=m·F(d)/ρ（实为 m·F(d)，方向 Δ̂ 已含单位化）。
- 排坑：curl 冒烟测试曾误报「能量翻倍」——实为 density=100 时中央核 R=1.78 吞掉
  r=1 测试轨道（核内线性力，语义正确）。
